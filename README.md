# Paul L. - Articles & Reading List

Personal website, digital library, and technical essay hub.

## Features

- **Reading List & Books Tracker**:
  - Track books in `Want to Read` (with priority tags), `Currently Reading` (with progress slider & page tracking), and `Completed` (with 5-star ratings, dates, and key takeaways).
  - Quick 1-click status transitions (`Start Reading`, `Finish`, `Re-queue`).
  - Search across titles, authors, categories, tags, and notes.
  - Add & edit books with full metadata, quotes, and takeaways.
  - Persistent state via `localStorage` with JSON export/import & reset utilities.
  - 2026 Reading Challenge goal progress meter.
- **Technical Articles & Essays**:
  - Technical writeups on static analysis, AST security linting, WebAssembly benchmarks, distributed caching, and component architecture.
  - Reader view with syntax highlighting, markdown tables, and quote callouts.
- **Design & Performance**:
  - Clean minimalist layout with light & dark themes.
  - Built with React 18, TypeScript, Tailwind CSS, Lucide icons, and Vite.

## Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Lint
npm run lint
```
